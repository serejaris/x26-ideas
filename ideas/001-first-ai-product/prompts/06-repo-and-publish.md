# 06. Репозиторий и публичная ссылка

## Когда использовать

В конце урока, когда есть HTML, PRD и варианты. Этот шаг превращает папку в демо-репозиторий, который можно показать.

## Промпт для агента

```text
Приведи эту папку в порядок как демо-репозиторий для идеи.

Нужно:
- проверить, что есть `prd.md` и `index.html`;
- проверить варианты `v<N>/index.html` и `v<N>/brief.md`;
- добавить или обновить `README.md` с короткой карточкой проекта;
- добавить или обновить `AGENTS.md` с правилами работы агентов;
- добавить или обновить `index.md` как реестр идей;
- добавить `.gitignore` для системных файлов, env-файлов и мусора;
- сделать первый логический коммит.

Не удаляй существующие идеи и варианты без подтверждения.
Не меняй `prd.md` по смыслу без подтверждения.
```

## Публикация через GitHub и Vercel

```text
Подготовь проект к публикации через GitHub и Vercel.

Проверь:
- репозиторий запушен;
- `index.html` открывается;
- ссылка на публичный репозиторий добавлена в учебную страницу;
- в README есть короткое объяснение, что это за демо.

Верни мне публичную ссылку на репозиторий и ссылку на опубликованную страницу, если она уже есть.
```

## Быстрый вариант без GitHub

Если нужно просто показать один HTML-файл:

```text
Подготовь один HTML-файл для ручной публикации через Netlify Drop.

Проверь, что файл автономный:
- всё в одном HTML;
- Tailwind подключён через CDN;
- нет локальных зависимостей;
- нет секретов и личных контактов.
```
