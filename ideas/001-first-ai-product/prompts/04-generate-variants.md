# 04. Сгенерировать три варианта

## Когда использовать

Когда есть `prd.md` и нужно посмотреть несколько разных визуальных направлений одной идеи.

## Промпт для агента в репозитории

```text
На основе `prd.md` сгенерируй три разных варианта дизайна.

Формат:
- каждый вариант в отдельной папке `v<N>/`;
- внутри каждого варианта строго два файла: `index.html` и `brief.md`;
- `brief.md` = исходный `prd.md` без правок + секция «Дизайн-решения этой версии» внизу;
- `index.html` = один самостоятельный HTML-файл.

Ограничения:
- Tailwind подключай только через CDN: `<script src="https://cdn.tailwindcss.com"></script>`;
- не добавляй `<style>` блоки;
- не добавляй inline `style=""`;
- не добавляй сборку, package.json и зависимости;
- используй семантический HTML: header, section, footer, осмысленные заголовки;
- сделай mobile-first адаптив через `md:` и `lg:` классы;
- для контактов используй плейсхолдер `https://t.me/your_handle`.

Сделай направления действительно разными: например, спокойное редакторское, тёплое дружелюбное и более смелое продуктовое.
```

## Что проверить

После генерации открой каждый `v<N>/index.html` и сравни не только красоту, но и конкретные решения: сетку, типографику, палитру, тон, плотность.
