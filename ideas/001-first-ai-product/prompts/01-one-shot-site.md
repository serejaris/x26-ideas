# 01. Первый HTML

## Когда использовать

В самом начале урока, когда у участника ещё нет структуры, но есть желание быстро увидеть результат.

## Промпт

```text
Сделай сайт про меня.

Формат: один HTML-файл.
Сайт должен открываться локально в браузере без сборки и зависимостей.

Пока не пытайся сделать финальную версию. Мне нужна первая простая версия, чтобы посмотреть, что получилось, и дальше уточнять.
```

## Вариации

```text
Сделай одностраничный сайт для моей идеи: [кратко опиши идею].

Формат: один HTML-файл.
Без сложной инфраструктуры, базы данных и авторизации.
Главная цель: получить видимую демку, которую можно открыть и показать другому человеку.
```

```text
Сделай интерактивную демку в одном HTML-файле: [что должно происходить на экране].

Демка должна работать локально в браузере.
Если нужна камера, кнопка, поле ввода или переключатели — добавь их прямо в HTML.
```

## Что объяснить участникам

Первая версия почти всегда будет слабой. Это нормально. Её задача — не быть красивой, а превратить идею в предмет разговора.
