# 05. Собрать центр идеи

## Когда использовать

После появления нескольких вариантов. Центр идеи нужен, чтобы быстро открыть все версии и показать маршрут.

## Промпт

```text
Сделай `index.html` для центра идеи.

Задача:
- кратко объяснить идею;
- показать ссылку на `prd.md`;
- показать карточки всех вариантов `v1`, `v2`, `v3`;
- у каждой карточки должны быть ссылка на `index.html` варианта и ссылка на `brief.md`;
- добавь короткое описание отличий каждого направления;
- внизу добавь ссылку обратно на общий `index.md` реестра.

Ограничения:
- один HTML-файл;
- Tailwind только через CDN;
- без `<style>` и без inline `style=""`;
- не добавляй сторонние JS-библиотеки;
- русский язык, коротко и понятно.
```

## Версия для этого урока

Если `index.html` используется как учебная страница, добавь:

```text
Сделай `index.html` не просто галереей, а уроком: маршрут занятия, методический контекст, ссылки на промпты и публичный репозиторий.
```
