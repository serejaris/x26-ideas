# Микро PRD: главная страница отдела x26-ideas

**Аудитория:** автор отдела, участники урока, гости по ссылке GitHub Pages — люди, которые хотят быстро понять, что это за репозиторий и куда идти дальше.

**Цель:** за 10 секунд объяснить, что x26-ideas — отдел HTML-идей (PRD → галерея → варианты), и дать явные входы: идея 001, реестр, публичный сайт.

**Результат:** человек понимает структуру, открывает галерею идеи 001 или сравнивает визуальные направления главной; при необходимости копирует бриф версии.

**Расширение для v4–v7 (библиотека идей):** главная как **визуальный каталог** — идея 001 видна сразу с **тремя визуальными слотами** (v1 Editorial, v2 Soft, v3 Bold). В интерфейсе: клик по варианту → превью/переход на лендинг; раскрытие **брифа** (fetch `brief.md` или `<details>` с ссылкой). v6–v7: **D3** через CDN (`https://d3js.org/d3.v7.min.js`) — граф связей «отдел → идея → варианты».

**Обязательный контент на странице:**

- Заголовок/бренд: x26-ideas · отдел идей
- Короткое описание (1–2 абзаца)
- Карточка идеи **001 · Первый продукт с AI** со ссылками:
  - `ideas/001-first-ai-product/index.html` — Галерея
  - `ideas/001-first-ai-product/prd.md` — PRD
- Ссылка на публичный сайт: `https://serejaris.github.io/x26-ideas/`
- Footer: `index.md` (реестр для агента), `README.md`
- Nav вверху (для вариантов v1–v3): `../../index.html` (галерея главных), `brief.md`

**Не включать:** реальные Telegram-хэндлы, секреты, лишние идеи кроме 001.

## Дизайн-решения этой версии

**Направление:** D3 Force Graph — интерактивная карта библиотеки: корень «x26-ideas», узел идеи 001, три дочерних варианта (Editorial / Soft / Bold). Связи видны как рёбра; узлы перетаскиваются, подписаны и окрашены по типу (`root` / `idea` / `variant`).

**Макет:** Tailwind для shell, nav, боковой панели и превью-плиток; D3 только для SVG `#graph` (симуляция `forceSimulation`, drag, клики). На мобиле панель стеком под графом (`flex-col`), на `lg+` — справа.

**Панель по клику:** узел идеи — краткое описание 001 + ссылка «Галерея»; узел варианта — три цветных прямоугольника-превью (имитация v1/v2/v3), кнопка «Открыть страницу», «Показать бриф» через `fetch` в `<pre class="text-xs overflow-auto max-h-64">`. Корень — подсказка про топологию отдела.

**Данные:** граф захардкожен в странице; ссылки на лендинги и `brief.md` вариантов идеи 001 — относительные пути `../../ideas/001-first-ai-product/…`.

**Ограничения:** без `<style>` и `style=""`; заливки узлов через D3 `attr('fill', '#hex')`; CDN Tailwind + D3 v7.
