# Микро PRD: главная страница отдела x26-ideas

**Аудитория:** автор отдела, участники урока, гости по ссылке GitHub Pages — люди, которые хотят быстро понять, что это за репозиторий и куда идти дальше.

**Цель:** за 10 секунд объяснить, что x26-ideas — отдел HTML-идей (PRD → галерея → варианты), и дать явные входы: идея 001, реестр, публичный сайт.

**Результат:** человек понимает структуру, открывает галерею идеи 001 или сравнивает три визуальных направления самой главной; при необходимости копирует бриф версии.

**Обязательный контент на странице:**

- Заголовок/бренд: x26-ideas · отдел идей
- Короткое описание (1–2 абзаца)
- Карточка идеи **001 · Первый продукт с AI** со ссылками:
  - `ideas/001-first-ai-product/index.html` — Галерея
  - `ideas/001-first-ai-product/prd.md` — PRD
- Ссылка на публичный сайт: `https://serejaris.github.io/x26-ideas/`
- Footer: `index.md` (реестр для агента), `README.md`
- Nav вверху (для вариантов v1–v3): `../../index.html` (галерея главных), `brief.md`

**Не включать:** реальные Telegram-хэндлы, секреты, лишние идеи кроме 001.

---

## Дизайн-решения этой версии

### Направление

**Modern Bold** — как у идеи 001 v3: тёмный нейтральный фон, кислотный лайм, жирный гротеск, строгая 12-колоночная сетка, уверенный тон на «вы». Главная отдела читается как продуктовый хаб, а не как «учебная заметка».

### Палитра

- Основа: `bg-neutral-950`, текст `text-neutral-100` / `text-neutral-300` / `text-neutral-400`
- Акцент: `lime-400` (марка, метки, CTA, hover)
- Контрастная полоса: `bg-lime-400 text-neutral-950` с формулой отдела
- Светлый блок карточки идеи: `bg-neutral-100 text-neutral-950` для читаемости ссылок
- Границы: `border-neutral-800`, hairline-сетки через `gap-px`

### Типографика

- H1: `font-black tracking-tight text-5xl md:text-7xl leading-[0.95]`
- Подзаголовки секций: капс `uppercase tracking-widest text-xs` + `font-black text-4xl`
- Body: `font-medium text-lg leading-relaxed`
- Без скруглений у кнопок и карточек (`rounded-none`)

### Структура страницы

1. **Nav** — `../../index.html` («галерея главных»), `brief.md` («Бриф v3»)
2. **Hero** — бренд с лаймовым квадратом, два абзаца про отдел, ссылка на GitHub Pages
3. **Полоса** — лаймовая строка: PRD → галерея → варианты
4. **Триада** — сетка 3 колонки (01 PRD / 02 галерея / 03 варианты)
5. **Идея 001** — светлая карточка на тёмном фоне, кнопки Галерея и PRD
6. **Footer** — `../../index.md`, `../../README.md`, метка v3

### Тон

Прямой, на «вы»: «вы открываете галерею», «вы сравниваете направления». Без эмодзи и без лишних идей — только 001 и служебные ссылки.

### Ограничения

- Только Tailwind CDN, без `<style>` и без `style="..."`
- Относительные пути к корню и `ideas/001-…` с префиксом `../../`
- Без Telegram и без секретов
